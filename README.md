# PhysTech 2026 — AI Biomechanics Analyzer

> Real-time exercise form analysis powered by MediaPipe Pose and AI coaching reports.
> Submitted to [PhysTech 2026 Hackathon](https://binnovative-boston.github.io/phystech/2026.html) — hosted by Binnovative.

---

## What it does

PhysTech 2026 is a full-stack web application that uses your webcam and AI to analyze your exercise form in real time. No wearables or sensors required.

- **Live pose detection** via MediaPipe Pose running entirely in the browser
- **Joint angle tracking** for knees, hips, back, and elbows on every frame
- **Real-time form alerts** when your movement deviates from safe ranges
- **Automatic rep counting** based on joint angle phase transitions
- **AI session reports** generated by an LLM coach at the end of each session
- **Progress dashboard** with charts tracking your form score and reps over time
- **User authentication** with per-user session history

### Supported exercises

| Exercise | Tracked angles | Counted metric |
|----------|---------------|----------------|
| Squat | Left/right knee, hip depth, torso lean | Reps via knee angle phase |
| Deadlift | Hip hinge, back rounding, knee bend | Reps via hip angle phase |
| Push-up | Elbow angle, full-body alignment | Reps via elbow angle phase |

## Getting started

### Prerequisites

- Node.js 18+
- MySQL 8+ running locally

### 1. Database setup

```bash
mysql -u root -p < database/schema.sql
```

### 2. Backend

```bash
cd backend
npm install
```

Create `backend/.env`:

```env
PORT=5000
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=phystech
JWT_SECRET=change_this_in_production

AI_API_KEY=your_nvidia_nim_key
AI_API_BASE_URL=https://integrate.api.nvidia.com/v1
AI_MODEL=minimaxai/minimax-m2.7
```

```bash
npm run dev
```

Backend starts on `http://localhost:5000`.

### 3. Demo user (optional)

```bash
cd database
node seed.js
```

Creates: `demo@phystech.com` / `demo1234`

### 4. Frontend

```bash
cd frontend
npm install
npm run dev
```

Frontend starts on `http://localhost:5173`. The Vite dev server proxies all `/api` requests to the backend automatically.

## How the pose analysis works

MediaPipe Pose detects 33 body landmarks per frame. The app extracts the relevant ones for each exercise and computes joint angles using the arctangent formula between 3 points:

```
angle at B = |atan2(C.y - B.y, C.x - B.x) - atan2(A.y - B.y, A.x - B.x)| × (180 / π)
```

### Form score

Starts at 100 and deducts 15 points per active alert. Clamped to [0, 100].

### Rep counting

Phase detection transitions (e.g. `up → down → up`) on the primary angle of each exercise:

| Exercise | Primary angle | Down threshold | Up threshold |
|----------|--------------|----------------|--------------|
| Squat | Left knee | < 110° | > 150° |
| Deadlift | Hip | < 100° | > 150° |
| Push-up | Left elbow | < 90° | > 150° |

A rep is counted on the `down → up` transition.

### Metrics sampling

One snapshot is saved to the buffer every 500 ms during a session. At session end the full buffer is sent to the backend and stored in `session_metrics`.

## AI coaching report

When a session ends, the backend sends aggregated metrics to the Nvidia NIM API:

- Average form score
- Average joint angles for the session
- Alert frequency table (alert type → count)
- Total reps and duration

The model returns structured JSON:

```json
{
  "overall_score": 82,
  "summary": "...",
  "strengths": ["..."],
  "improvements": ["..."],
  "injury_risk": "low",
  "injury_risk_reason": "...",
  "next_session_tip": "..."
}
```

The report is cached in the `sessions.ai_report` column so it is only generated once per session.

## Database schema

```sql
users (id, name, email, password_hash, created_at)

sessions (
  id, user_id, exercise_type ENUM('squat','deadlift','pushup'),
  duration_seconds, total_reps, avg_form_score, ai_report, created_at
)

session_metrics (
  id, session_id, timestamp_ms,
  left_knee_angle, right_knee_angle, hip_angle, back_angle, elbow_angle,
  form_score, alert_type, rep_count
)
```
